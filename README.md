\# Answer Pilot



AI-powered exam answer generator that uses Retrieval-Augmented Generation (RAG) to generate clear, structured and exam-ready answers from uploaded study materials.



\## Features



\- Upload college PDF study materials

\- Extract text from PDFs

\- Split documents into meaningful chunks

\- Generate semantic embeddings

\- Store and retrieve knowledge using ChromaDB

\- Generate answers using Google Gemini

\- Support different answer types such as 2, 5 and 10 marks

\- Control answer length

\- Support multiple languages

\- Exam-friendly formatting

\- PDF answer export

\- Diagram support

\- Clean student-focused interface
